# webservco/symfony-project-skeleton

A Symfony project template.

Minimal Symfony 7.4 web application with Twig, Doctrine, AssetMapper and Stimulus, a ddev setup and strict code validation already wired in.

- Requires: PHP 8.4+, [ddev](https://ddev.com/)
- Includes: Twig, Doctrine ORM and migrations, AssetMapper, Stimulus and Turbo, the debug toolbar and profiler, Monolog
- Validation: PHP_CodeSniffer, PHPStan, Psalm, Phan, PHPMD and Twig CS Fixer, configured by `webservco/coding-standards`

---

## Installation

```shell
git clone git@github.com:webservco/symfony-project-skeleton.git example-project
cd example-project
git remote rename origin vendor-origin
git remote add origin git@github.com:example/example-project.git
```

Then customize the project:

- Set `name` in `.ddev/config.yaml`.
- Replace this README.
- Replace `LICENSE.md` with your project's license, or delete it. `composer.json` already says `proprietary`.
- Set a new `APP_SECRET` in `.env.dev`.

```shell
git branch -M main
git push -u origin main
```

## Usage

```shell
# Start project.
ddev start
# Install dependencies.
ddev c u
# Run Symfony console commands.
ddev sc debug:router
```

Controllers go in `src/Controller/` and are routed by attribute. Entities go in `src/Entity/`, repositories in `src/Repository/` and migrations in `migrations/`. Templates extend `templates/base.html.twig`.

---

## Notes

The ddev configuration omits the database container, but `.env` already points `DATABASE_URL` at the ddev database. To use Doctrine, remove `db` from `omit_containers` in `.ddev/config.yaml` and restart ddev.

Without Doctrine, switch the includes in `phpstan.neon` from `phpstan-symfony-doctrine.neon` to `phpstan-symfony.neon`, and the Psalm config in `composer.json` from `psalm-symfony-doctrine.xml` to `psalm-symfony.xml`.

`config/reference.php` is generated by Symfony and gitignored, so every check excludes it.

## Development

```shell
# Run all validations.
ddev c c
# Fix code style.
ddev c fix:phpcs
ddev c fix:twig
# Run unit tests.
ddev c test:dox
```
